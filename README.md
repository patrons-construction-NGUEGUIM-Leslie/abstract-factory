# Patron Abstract Factory

Devoir 1 - INF461 - Patrons de construction

## Contenu
- src/cours : exemple du cours (ProduitA et ProduitB, deux familles de produits)
- src/modifie : exemple modifie (Scooter et Automobile, trois familles : Essence, Electrique, Hybride)
- diagrammes : diagrammes de classes (modele generique, exemple du cours, exemple modifie)

## Compilation et execution
cd src
javac cours/*.java
java cours.Client

javac modifie/*.java
java modifie.ClientVehicules
